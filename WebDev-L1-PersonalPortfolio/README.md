
# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my profile, technical skills, projects, educational background, and contact information in a modern and responsive design.

## 🚀 About the Project

This is a personal portfolio website developed using HTML5 and CSS3. It serves as my digital resume, allowing recruiters, developers, and visitors to learn more about me and explore my work.

## ✨ Features

- 🏠 **Home Section:** Introduction with profile photo and role.
- 👨‍💻 **About Me:** Educational background and career interests.
- 🛠️ **Skills Section:** Displays my technical skills.
- 📂 **Projects Section:** Showcases my development projects.
- 📧 **Contact Section:** Contact information and social links.
- 📱 **Responsive Design:** Supports desktop, tablet, and mobile devices.
- 🎨 **Modern UI:** Attractive dark theme with purple accents.
- 🔗 **Smooth Navigation:** Easy navigation between sections.

## 💻 Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/yourusername/personal-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd personal-portfolio
   ```

3. Open the `index.html` file in your browser.

   Alternatively, use the Live Server extension in VS Code.
