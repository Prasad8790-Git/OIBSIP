🌐  Temperature Converter Website

🚀 About
A responsive temperature converter built using HTML, CSS,
and Vanilla JavaScript.

It converts temperatures between Celsius, Fahrenheit,
and Kelvin.

✨ Features
- Convert Celsius to Fahrenheit and Kelvin.
- Convert Fahrenheit to Celsius and Kelvin.
- Convert Kelvin to Celsius and Fahrenheit.
- Input validation.
- Absolute zero error handling.
- Responsive user interface.
- Instant conversion results on button click.

💻 Technologies Used
- HTML5
- CSS3
- JavaScript

temperature-converter/

⚙️ How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Enter a temperature.
5. Select the input unit.
6. Click Convert Temperature.
